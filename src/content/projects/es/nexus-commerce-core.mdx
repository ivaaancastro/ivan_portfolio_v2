Proyecto full-stack personal construido con estándares de ingeniería de producción: un backend transaccional para retail multimercado con Spring Boot y una vitrina editorial en Next.js. Todo el desarrollo sigue Spec-Driven Development, con specs, ADRs y changelog versionados.

## Motores de negocio

- **Catálogo:** productos con variantes físicas (SKU) organizados por familia, con consultas optimizadas sin N+1.
- **Precios multimercado:** tarificación multidivisa (ES/US/UK/CH) con desglose impositivo, toda la aritmética financiera en BigDecimal.
- **Inventario omnicanal:** cálculo ATS y bloqueo pesimista (`SELECT ... FOR UPDATE`) para impedir el over-selling.
- **Checkout transaccional:** idempotencia por cabecera, snapshot financiero inmutable y devoluciones con ventana de 30 días.
- **Búsqueda híbrida con IA:** embeddings con pgvector (HNSW) vía Spring AI, con fallback a texto cuando no hay API key.
- **Panel de administración:** roles ADMIN/USER con JWT y gestión de catálogo, stock y precios.

## Calidad y proceso

- **Unos 1.000 tests** (≈450 backend con >90 % de cobertura, ≈550 frontend) y E2E con Playwright en 3 navegadores.
- **Auditorías en CI:** accesibilidad con axe sobre las rutas públicas, de usuario y de administración y Core Web Vitals con Lighthouse, ambas en verde.
- Arquitectura en capas con DTOs inmutables, errores semánticos RFC 7807 y documentación OpenAPI/Swagger.
