This project was born to manage a modern gym ecosystem, combining high sports performance with quality software engineering.

## Technical highlights

- **Architecture:** clear separation between the business core (Java) and the reactive interface (React).
- **Infrastructure:** Docker image deployed to Kubernetes with Eclipse JKube.
- **Quality:** backend (JUnit) and frontend tests, coverage with JaCoCo and load tests with k6.
